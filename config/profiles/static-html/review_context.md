For static HTML web projects, also judge the visual and UX realism from the current files.

Pay attention to:
- semantic structure of the page
- plausibility of hero, CTA, cards, spacing, and hierarchy
- whether the layout is likely centered and not broken
- whether CSS choices match the stated design goals
- whether placeholder/demo content is creeping back in
- whether the implementation feels like a real web page rather than a mockup fragment

Do not demand pixel-perfect design.
Request changes only if the visual result is likely wrong, broken, or clearly below the task requirements.
